# EndpointSecurityDemo Documentation

Welcome to the official documentation for the EndpointSecurityDemo application. This documentation provides comprehensive information about the architecture, setup procedures, and features of this macOS security monitoring tool.

## Overview

EndpointSecurityDemo is a powerful demonstration of Apple's EndpointSecurity framework capabilities. It provides real-time monitoring and control of system events, with enhanced features that emulate and extend Gatekeeper and XProtect functionality.

## Key Features

- Real-time monitoring of system events
- Process execution control (similar to Gatekeeper)
- Malware detection capabilities (similar to XProtect)
- Configurable security policies
- Support for both serial and asynchronous event handling
- Detailed logging and notification system

- macOS Catalina (10.15) or later
- Xcode 16 or later for building
- Administrative privileges for installation
- Special entitlements for EndpointSecurity access
